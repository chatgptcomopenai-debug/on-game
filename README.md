# 👑 Избранный

Онлайн-арена для телефона с видом сверху. Один игрок — Избранный со случайной сверхсилой и короной, остальные охотники ищут оружие на острове и пытаются его свалить. Добил Избранного — сам стал им. Первый до 10 очков короны побеждает.

## 📲 Скачать

- **Android (APK):** [izbrannyi.apk](https://github.com/chatgptcomopenai-debug/on-game/releases/latest/download/izbrannyi.apk)
- **Браузер (любой телефон или ПК), одним файлом:** [izbrannyi.html](https://github.com/chatgptcomopenai-debug/on-game/releases/latest/download/izbrannyi.html)
- Все сборки: [Releases](https://github.com/chatgptcomopenai-debug/on-game/releases)

Пароль для входа: **12345687**, ник — любой.

### Как установить APK
1. Открой ссылку выше на Android-телефоне и скачай файл.
2. Открой скачанный `izbrannyi.apk`. Если телефон спросит — разреши установку из этого источника (браузера или «Файлов»).
3. Запусти «Избранный». Для игры по сети нужен интернет; с ботами можно играть и без него.

APK собирается автоматически (GitHub Actions) при каждом обновлении кода, ссылка всегда ведёт на последнюю версию.

## 🎮 Как играть
- Джойстик слева — бег. Большая кнопка справа — атака: нажал — автонаводка, держишь — автоогонь, тянешь пальцем — целишься сам.
- 💨 — перекат с неуязвимостью, ★ — навык героя, 💥 — ульта Избранного.
- Очки получает только Избранный: +1 за выбитого охотника и +1 за каждые 15 секунд с короной.
- Онлайн: «Создать комнату» → скажи друзьям код из 5 символов → они вводят его в «Войти».

## 🛠 Для разработки
- Код игры — `src/`, все числа баланса — `src/config.js`.
- Собрать один HTML: `python3 tools/build.py` → `izbrannyi.html`.
- Android-обёртка — `android/` (WebView), сборка — `.github/workflows/apk.yml`.
