# Задача
Найти лучшую реализацию мобильной онлайн-игры «Избранный» (рабочее название) и выдать один полный технический + геймдизайн-план реализации.

## Игра (от пользователя)
- Онлайн, для телефонов (браузер, горизонтальная ориентация), управление: виртуальный джойстик слева + 2–3 кнопки справа.
- Асимметричная арена 3–6 игроков: одному случайному игроку достаётся рандомная сверхсила (Пламя, Молния, Лёд, Гигант), остальные — охотники, должны его одолеть.
- Добивший Избранного становится следующим Избранным. Раунды 90 с, матч 5 раундов, очки, экран итогов.
- Желательно без собственного сервера (P2P/PeerJS), либо лёгкий бесплатный сервер. Хостинг статики — GitHub Pages.
- Предварительный стиль — неон на тёмном фоне (рисуется кодом).
- Вход в комнату по коду.
- Проект делается в пустом git-репозитории; минимальный уровень строгости (один бриф, затем код), MVP не больше 7 пунктов.

## Что решить
1. Сетевая архитектура (P2P host-authoritative vs WebSocket-сервер vs иное) — с учётом мобильного интернета, NAT, ухода хоста.
2. Рендер/движок (Canvas2D vs Phaser vs PixiJS vs иное).
3. Структура кода (файлы/модули), игровой цикл, фиксированный тик.
4. Синхронизация: частота снапшотов, интерполяция, предсказание, ввод.
5. Неоновый стиль на телефоне без потери FPS.
6. Баланс Избранного vs охотников (числа: HP, урон, скорость, кулдауны, масштабирование от числа игроков), 4 сверхсилы.
7. MVP-порядок сборки по шагам.

## Готово, когда
Один связный план, по которому разработчик сразу начнёт писать код: конкретные решения с обоснованием, числа, структура файлов, порядок работ, риски.
