# Бриф: «Избранный» (рабочее название)

**Питч:** онлайн-арена для телефона: одному случайному игроку достаётся случайная сверхсила, остальные вместе пытаются его одолеть. Добивший становится следующим Избранным.

**Вид и стиль (решение пользователя):** 2D сбоку, камера неподвижна, весь парящий островок на экране. Пиксель-арт персонажи 12×18 (база как в референсе + футболка цвета игрока). Над каждым игроком — метка его цвета с устройством (iPhone/Android/ПК) и стрелочка; у своего — «ТЫ».

**Цикл:** раунд → Избранный с силой охотится → охотники бьют его → добивший получает силу → очки. 5 раундов × 90 с.

**Техника и баланс:** см. design/implementation-plan.md (результат арены). Отличие: вместо вида сверху — платформер (гравитация, прыжок, проходимые платформы), неон заменён пиксель-артом.

**MVP:** 1–6 ✅ (каркас, бой, сеть PeerJS, выходы игроков, 4 силы, матч+итоги), режим с ботами ✅, вход: ник + общий пароль ✅. Осталось: плейтест на реальных телефонах, предсказание своего движения для клиента.
