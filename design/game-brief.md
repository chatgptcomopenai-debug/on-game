# Бриф: «Избранный» v3

**Питч:** онлайн-арена для телефона. Один игрок — Избранный со сверхсилой, остальные охотники ищут оружие на карте и вместе его валят. Добивший забирает силу.

**Вид:** 2D сбоку, пиксель-арт, мир 768×384; камера плавно держит в кадре всех игроков и точку прицела (в меню можно включить «вся карта»). Свечение, частицы, параллакс фона.

**Карты (6, по 5 за матч в случайном порядке):** Небесный луг (ураган), Вулкан (гейзеры, движущийся мост), Ледяной пик (скользко, сосульки), Грибной лес (грибы-батуты, ядовитые споры), Небесный храм (движущиеся платформы, гроза), Неон-сити (крыши, лазерная зачистка).

**Охотники:** без суперсил. Оружие только с карты: пистолет, автомат, дробовик, снайперка, гранатомёт, базука, лазер (патроны кончаются). Без оружия — кулак (3 урона, сильный толчок).
**Герои (8, навык на ★):** Боец (рывок), Ниндзя (тройной прыжок, теневой рывок), Рыцарь (щит), Медик (лечение), Инженер (турель), Призрак (невидимость), Ракетчик (ракетный прыжок), Робот (ЭМИ-оглушение).

**Избранный (8 сил × атака/★/ульта):** Пламя, Молния, Лёд, Гигант, Яд, Тень, Гравитация, Ветер.

**Прицел:** тап — автонаводка (рамка на цели), удержание — автоогонь, потянуть кнопку — линия/дуга/кружок, отпустить — выстрел. ПК: мышь.

**Честность:** Избранным становятся по очереди (кто реже был), бот-Избранный выбирает цели случайно с учётом расстояния и меняет их.

**Мета:** уровни, монеты, шапки, выбор героя; боты 3 уровней; онлайн-комнаты PeerJS; вход ник + общий пароль.

Числа — src/config.js. Сборка одного файла: `python3 tools/build.py`.
